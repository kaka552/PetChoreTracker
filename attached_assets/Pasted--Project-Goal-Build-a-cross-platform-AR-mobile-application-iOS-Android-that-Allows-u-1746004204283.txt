

### **Project Goal**
Build a cross-platform AR mobile application (iOS + Android) that:
- Allows users to scan images to view mapped 3D models.
- Supports two roles: **User** and **Dev (Developer/Admin)**.
- Offers role-based access control.
- Provides interactive model view and admin model management.

### **Feature List**

#### 1. **Authentication System (Initial Focus)**
- **Sign In / Sign Up**
- Role-based access: User / Dev
- Use **Supabase Auth** to manage credentials and roles.

#### 2. **Role-Based Access**
- **User View** (Welcome Page)
  - Camera scan button
  - Logout button (bottom-right)
- **Dev View** (Welcome Page)
  - All user features +
  - Upload 3D model + image + description
  - Edit or update existing model mappings

#### 3. **Camera & AR Flow**
- Click camera image button → Go to **AR scanning scene**
- Scan image → Load corresponding 3D model
- Load model in **new scene** for interaction:
  - Zoom / Rotate / Drag
  - **Double-tap** on model → Show description
- **Navigation:**
  - Back button in AR scan scene → Welcome Page
  - Back button in model view → AR scan scene

### **Database Design (via Supabase)**

1. **Users Table**
   - `id`, `email`, `role` (user/dev)

2. **Models Table**
   - `id`, `model_name`, `image_target`, `model_file_url`, `description`, `uploaded_by`

3. **Model Mapping Table (Optional)**
   - `model_id`, `image_id`, `target_name`, `position_data`, etc.
